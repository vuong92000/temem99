👋 Chào mừng đến PhotoAI Studio

Studio chỉnh sửa ảnh AI chuyên nghiệp ngay trong trình duyệt. Tải ảnh lên, chọn công cụ, AI xử lý — tải kết quả về máy.

🚀 4 bước sử dụng

  1. Nhập API key Gemini (miễn phí) hoặc OpenAI trong ⚙️ Cài đặt API.
  2. Tải ảnh lên — kéo thả, dán (Ctrl+V) hoặc dùng ảnh mẫu.
  3. Chọn công cụ, chỉnh tùy chọn → nhấn ⚡ Xử lý bằng AI.
  4. Kéo thanh so sánh Trước/Sau, ưng ý thì tải về.

⚙️ Cài đặt API & Model AI

✨ Google Gemini Miễn phí

Lấy key miễn phí tại aistudio.google.com/apikey → “Create API key”.

🤖 OpenAI GPT Image Trả phí

Lấy key tại platform.openai.com/api-keys (cần nạp credit).

🔒 Key được lưu chỉ trong trình duyệt này (localStorage). Không dùng chung máy tính lạ. Xóa key bất cứ lúc nào bằng cách xóa nội dung ô và lưu.

❓ Hướng dẫn sử dụng

1️⃣ Lấy API key

  • Gemini (miễn phí, khuyên dùng): vào aistudio.google.com/apikey → đăng nhập Google → Create API key → copy key dán vào ⚙️ Cài đặt API.
  • OpenAI GPT (trả phí, ảnh rất đẹp): vào platform.openai.com/api-keys → tạo key (đầu sk-) → nạp credit → dán vào Cài đặt.

2️⃣ Quy trình chỉnh ảnh

  • Tải ảnh: kéo-thả, Ctrl+V dán ảnh chụp màn hình, hoặc dùng ảnh mẫu.
  • Chọn engine ✨ Gemini / 🤖 GPT trên thanh trên cùng.
  • Chọn công cụ ở menu trái, chỉnh tùy chọn, nhấn ⚡ Xử lý bằng AI.
  • Kéo thanh ⇔ để so sánh Trước–Sau. Nhấn 🔁 để lấy kết quả chỉnh tiếp nhiều bước.

3️⃣ Mẹo từng công cụ

  • 🪪 Ảnh thẻ: ảnh gốc càng rõ mặt càng đẹp. Sau khi tạo, dùng 🖨️ Tấm in để in khổ 10×15.
  • 💡 Ánh sáng: thử nút 🤖 AI gợi ý để máy tự chọn kiểu sáng hợp mặt.
  • 🕰️ Phục hồi: ảnh nát nặng → mức Mạnh + chạy 2–3 lần, mỗi lần 1 tính năng.

⌨️ Phím tắt

  • Ctrl+Enter: chạy AI · Ctrl+V: dán ảnh · 123: đổi công cụ
